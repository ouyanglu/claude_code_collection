# 国内大模型免费Token领取指南

一个精美的网页，展示各大国内大模型厂商的免费API调用额度领取信息。

## 项目结构

```
.
├── index.html          # 主页面（原 free-model-tokens.html）
├── vercel.json         # Vercel配置文件
├── public/             # 静态资源目录
│   └── index.html      # 重定向页面
└── README.md           # 项目说明
```

## 部署到Vercel

1. 确保代码已推送到GitHub
2. 在Vercel控制台导入项目
3. Vercel会自动识别为静态网站
